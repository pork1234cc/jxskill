# 对标工具数据契约

## 账号登记

- 只接受抖音或微信视频号作品链接。
- TikHub 解析账号后，按“平台 + API查询ID”幂等新增或更新当前模式的唯一账号源。
- `local` 模式使用 `1-对标账号/accounts.md`；用户可删除账号整行停止监控，但不得修改格式标记、表头或账号 ID。
- `feishu` 模式使用飞书账号表，不读取或写入本地账号清单；用户可在飞书删除账号行停止监控。
- 本地表格或飞书表结构、稳定 ID、必填字段无效时停止，禁止静默覆盖或同时写两个账号源。
- 登记完成后不得读取作品列表、下载、解密或调用 ASR。

## 手动提取文案

- 只接受唯一的抖音或微信视频号公开视频链接；一次命令只处理一条作品。
- 直接读取单作品详情，不登记账号、不读取账号作品列表，也不应用监控时间窗口或传播指标。
- 案例 ID 仍为 `douyin_<aweme_id>` 或 `wechat_channels_<object_id>`，并递归检查 `2-素材库/` 与 `3-对标案例/文案/`。
- 已有相同案例 ID 时返回文件当前路径，不下载媒体、不解密、不调用 ASR。
- 新作品完成媒体处理和 ASR 后直接保存到 `3-对标案例/文案/`，不进入监控候选素材库。
- `local` 模式只保存本地 Markdown；`feishu` 模式把已有或新增案例幂等同步到案例表，但不要求或访问账号表。

## 监控窗口与扫描

- 从当前模式的唯一账号源读取账号，按返回顺序串行处理。
- 默认窗口是执行时刻向前 72 小时，刚好 72 小时包含；用户明确提供正数小时或天数时替换默认窗口，未来异常时间始终排除。
- 每账号每渠道最多读取五页；旧作品乱序时只额外读取一页。
- 抖音普通作品列表没有窗口内作品时，可从第一页切换一次极速版列表。
- 非视频作品跳过。

## 默认新素材门槛

- 未提供自定义指标条件时使用本节默认门槛。
- 转发数至少 500。
- 点赞数大于零时，转发数除以点赞数必须大于或等于 1.5。
- 点赞数为零或负值时，不执行除法；转发达到 500 即通过。
- 未达门槛作品不下载、不 ASR、不写 Markdown；在 72 小时窗口内继续复查。

## 自定义新素材门槛

- 支持点赞、收藏、评论、转发和转赞比；转赞比固定为转发数除以点赞数。
- 显式条件支持大于等于、大于、小于等于、小于和等于；未写比较词的“指标 + 数字”按大于等于处理。
- 一旦提供自定义指标条件，就整体替换原有指标门槛；没有提到的指标不参与筛选。
- 多个条件默认使用“且”；只有用户明确说“或”或“任一”时才使用“或”。混合“且/或”的表达必须先澄清。
- 自定义指标缺失时该条件不通过；转赞比条件遇到点赞数为零或缺失时，比例条件不通过。
- 自定义条件只筛选新素材；已有案例仍绕过门槛，只刷新数据且不重复 ASR。
- 未达自定义门槛的作品不下载、不 ASR、不写 Markdown，并在实际时间窗口内继续复查。

## 本地目录和幂等

- 监控新增素材保存到项目根 `2-素材库/<账号中文名称>/`；手动提取的新文案保存到 `3-对标案例/文案/`。
- 文档标题和基础文件名取平台标题或描述前 20 个字符；Windows 非法字符必须清理。
- 二十字标题重名时追加作品 ID 后六位，仍冲突时追加完整作品 ID，禁止覆盖。
- 案例 ID 为 `douyin_<aweme_id>` 或 `wechat_channels_<object_id>`。
- 去重同时递归检查 `2-素材库/` 和 `3-对标案例/文案/`。
- 人工移动文件后，监控只能在原位置更新，不得重新采集或移回素材库。

## 已有案例刷新

- 已有案例不重新应用传播门槛，不下载、不解密、不重复 ASR。
- 只刷新点赞、收藏、评论、转发和数据更新时间。
- 不写播放数、`read_count`、评分或互动率。
- `local` 模式只刷新本地；`feishu` 模式刷新本地后幂等更新案例表。

## 媒体、ASR 和失败处理

- 视频号媒体 URL 与 `decode_key` 必须来自同一次列表响应。
- 抖音只在列表媒体地址缺失时补查一次详情。
- 下载、解密、媒体验证或 ASR 失败时不建立成功案例，下轮自动重试该作品。
- 无有效口播时仍落盘“无有效口播”状态，避免反复 ASR。
- 媒体与 ASR 中间文件只位于项目 `.tmp/`，成功或失败后都清理；长期只保留 Markdown。
- 单作品失败继续本账号，单账号失败继续后续账号，最终汇总具体错误。
- 飞书案例同步失败时保留本地 Markdown 并计入失败；下轮监控从本地文件重建记录再次同步，不重复 ASR。
- 飞书只接收账号字段、案例元数据和清洗逐字稿；媒体、音频、临时文件和密钥不得上传。
