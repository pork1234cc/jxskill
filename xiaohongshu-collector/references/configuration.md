# 配置说明

## 配置位置

采集器从环境变量或当前工作项目根目录的 `.env` 读取凭据。不要把真实 `.env` 放进 Skill 目录，也不要提交到 Git。

克隆整个 `jxskill` 仓库时，从仓库根目录执行命令，使用 `.venv/Scripts/python.exe` 和根目录 `.env`，与监控 Skill 共用运行环境。小红书专属表参数仍使用 `NOTE_TOKEN`、`NOTE_WORK`、`NOTE_CONTENT`，不与监控的账号表和案例表合并。Skill 单独安装后，以用户正在操作的工作区作为配置和输出根目录。

首次配置时，将 `assets/.env.example` 复制到正在操作的项目根目录并命名为 `.env`，然后填写实际值。

## TikHub

真实采集必须配置：

```dotenv
TIKHUB_API_KEY=
```

TikHub 请求可能计费。缺少该变量时，采集入口必须中止，不得构造空凭据请求。

## 飞书多维表格

需要把结构化结果写入飞书时配置：

```dotenv
FEISHU_APP_ID=
FEISHU_APP_SECRET=
NOTE_TOKEN=
NOTE_WORK=
NOTE_CONTENT=
# 可选预留，当前不采集或写入评论
NOTE_COMMENT=
```

其中 `NOTE_TOKEN` 是多维表格 App Token，`NOTE_WORK` 是采集任务表 ID，`NOTE_CONTENT` 是笔记详情表 ID。`NOTE_COMMENT` 是预留的可选评论表 ID，当前不采集或写入评论。

参数名称统一使用上述名称，非空进程环境变量优先于 `.env` 文件；缺少必填配置时，错误提示也使用上述名称。

2026-09-05：代码、测试和两份配置模板统一为项目 `.env` 使用的 `NOTE_*` 名称，移除旧名称兼容。后续调整配置名称时必须同步读取逻辑、模板、说明和测试，避免仅添加别名而遗漏模板。

飞书配置不完整时，只执行本地采集并明确报告没有写入飞书。飞书写入失败时，使用已保存的本地结果排查或恢复，禁止重新调用 TikHub 采集。

## 首次自动创建字段

先在飞书创建采集任务表和笔记详情表，可以保留默认字段，再把两张表的 ID 分别填入 `NOTE_WORK`、`NOTE_CONTENT`。两张表必须不同。飞书应用需要访问这两张表，以及读取和创建字段、读写记录的权限。

运行 `collect` 或 `tasks` 时，采集器会先分页读取两张表的字段，校验已有字段，并自动创建缺失字段。任务表即使没有“未采集”记录，也会先完成字段初始化，再提示没有待采集任务。

| 数据表 | 字段类型 | 字段名称 |
|--------|----------|----------|
| 采集任务表 | 文本 | 任务ID、搜索关键词 |
| 采集任务表 | 数字 | 采集数量、最低点赞数、最低收藏数、最低评论数 |
| 采集任务表 | 单选 | 排序依据、笔记类型、发布时间、采集状态 |
| 笔记详情表 | 数字 | 点赞、收藏、评论、转发 |
| 笔记详情表 | 文本 | Note ID、作者昵称、用户ID、标题、正文、话题、原文链接、来源关键词、首次任务ID |

新增单选字段会包含 [采集规范](collection-spec.md) 中的完整选项。“原文链接”使用文本字段，与当前记录写入格式一致；各类 ID 使用文本以保留原始值。

- 只创建缺失字段，不删除、重命名或转换已有字段，也不修改已有记录；默认字段和用户自建字段保留。
- 已有同名字段类型不符，或已有单选字段缺少规定选项时，明确报错并停止，请先在飞书中调整对应字段。
- 两张表都校验通过后才开始创建；权限不足或创建请求失败时立即停止，不发起 TikHub 采集。
- 部分字段已创建后发生失败，再次运行会读取当前结构并补齐剩余字段，不重复创建成功的字段。
- 不自动创建多维表格、数据表或评论字段；`NOTE_COMMENT` 仍为可选预留。

2026-09-05：两个采集入口接入字段初始化，空表首次运行自动补齐任务表 10 个字段和笔记详情表 13 个字段。

字段接口参考：[列出字段](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-field/list)、[新增字段](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-field/create)。

## 敏感信息规则

- 模板只保留变量名和空值。
- 日志、测试输出和错误消息不得显示完整 Token 或 Secret。
- 测试使用 Mock，不连接真实 TikHub 或飞书服务。
