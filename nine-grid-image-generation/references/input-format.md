# 九宫格标准输入合同

## 用户输入

用户可以直接给一个主题，也可以给出带编号的 9 个场景。Skill 负责把自然语言转换成脚本使用的 JSON，用户不需要手写 JSON。

推荐的自然语言格式：

```text
主题：春日江南生活
比例：9:16
风格：电影感国风摄影
统一要求：同一时段、柔和薄雾、低饱和青绿色，不出现文字和水印

1. 左上：清晨薄雾中的江南古镇
2. 上中：河边洗衣的妇人
3. 右上：石桥上撑伞行人
4. 左中：临河茶馆
5. 正中：乌篷船穿过水巷
6. 右中：老人在窗边读书
7. 左下：雨水落在青石板上
8. 下中：黄昏灯笼亮起
9. 右下：夜色中的古镇全景
```

## JSON Schema

脚本接收以下 UTF-8 JSON 对象：

```json
{
  "title": "春日江南生活",
  "ratio": "9:16",
  "style": "电影感国风摄影",
  "global_requirements": "同一时段、柔和薄雾、低饱和青绿色，不出现文字和水印",
  "scenes": [
    {"slot": 1, "prompt": "清晨薄雾中的江南古镇"},
    {"slot": 2, "prompt": "河边洗衣的妇人"},
    {"slot": 3, "prompt": "石桥上撑伞行人"},
    {"slot": 4, "prompt": "临河茶馆"},
    {"slot": 5, "prompt": "乌篷船穿过水巷"},
    {"slot": 6, "prompt": "老人在窗边读书"},
    {"slot": 7, "prompt": "雨水落在青石板上"},
    {"slot": 8, "prompt": "黄昏灯笼亮起"},
    {"slot": 9, "prompt": "夜色中的古镇全景"}
  ]
}
```

字段规则：

| 字段 | 必填 | 规则 |
|---|---|---|
| `title` | 是 | 非空字符串，只用于输出记录 |
| `ratio` | 是 | `1:1`、`3:4`、`4:3`、`9:16`、`16:9` 之一 |
| `style` | 否 | 视觉媒介、色彩、光线和镜头风格；默认“自然、统一、清晰的电影感画面” |
| `global_requirements` | 否 | 适用于全部九格的统一要求和禁止项 |
| `scenes` | 是 | 必须恰好 9 项 |
| `scenes[].slot` | 是 | `1` 到 `9`，不得重复或跳号 |
| `scenes[].prompt` | 是 | 非空场景描述，每格只描述一个静态动作阶段 |

## 单主题自动规划

用户只给一个主题时，按以下顺序规划九格：

1. 环境建立；
2. 核心主体；
3. 关键动作；
4. 空间关系；
5. 主题主画面；
6. 细节证据；
7. 变化或反差；
8. 结果状态；
9. 收束全景。

这只是叙事职责，不要求机械使用固定景别。根据主题自然选择主体和场景，避免九格仅改变机位、颜色或远近。

## 比例与 API 尺寸

| 比例 | 总图请求尺寸 | 单格输出尺寸 |
|---|---:|---:|
| `1:1` | `2880x2880` | `960x960` |
| `3:4` | `2448x3264` | `816x1088` |
| `4:3` | `3264x2448` | `1088x816` |
| `9:16` | `2160x3840` | `720x1280` |
| `16:9` | `3840x2160` | `1280x720` |

总图与单格保持相同比例；3×3 划分后，每格可以直接等比归整到表中的目标尺寸。

## 校验失败

以下情况在调用 API 前直接拒绝：

- JSON 不是对象；
- 比例不受支持；
- 场景不是恰好 9 个；
- slot 缺失、重复、越界或顺序不完整；
- 任意场景 Prompt 为空；
- 输入文件不是 UTF-8 JSON。
